# 发布

服务以 **Python 包（wheel/sdist）** 和 **Docker 镜像** 两种形态发布，版本号在
`pyproject.toml`，变更写 `CHANGELOG.md`。

## 1. 发布前

```bash
uv sync --group dev
./scripts/check.sh          # 9 部门禁全绿
uv build                    # dist/*.whl + dist/*.tar.gz
```

数据库迁移必须已经在 `alembic/versions/` 里，且 `alembic check` 无漂移。
容器入口会自动执行 `alembic upgrade head`，升级前仍建议备份 `var/ccnr-data.db`。

## 2. 打 tag

```bash
git tag v0.1.0
git push origin v0.1.0
```

`release.yml` 会重跑门禁、构建 wheel/sdist，并把 `dist/*` 附到 GitHub Release。

## 3. Docker

```bash
docker compose up -d --build
```

镜像基于 `python:3.12-slim`，代码与生成桩一起打进镜像；`var/` 挂到 `/data`。
升级时重新 `docker compose up -d --build`，入口自动迁移。

## 4. 版本约定

- 修复：`0.1.x`
- 兼容新增：`0.x.0`
- 破坏协议 / schema：升 `x`，并在 CHANGELOG 写明迁移步骤。
